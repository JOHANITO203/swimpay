# Task 011 — Hosted Checkout

## Goal

Implement buyer checkout UI.

## Read first

- `docs/13_UX_CHECKOUT.md`
- `docs/06_API_SPEC.md`

## Requirements

Implement screens:

- Checkout Summary;
- Buyer Identity;
- Payment Instructions;
- Waiting Confirmation;
- Result.

Include:

- amount;
- timer;
- recipient;
- reference;
- copy buttons;
- open bank button placeholder;
- `J’ai payé` button;
- status polling.

## Acceptance criteria

- UI does not claim official bank confirmation.
- Buyer phone explanation is shown.
- `J’ai payé` does not confirm payment.
- Status reflects backend order/session states.
