# Task 732 - Checkout UX design plan

Status: completed

Objective:
Define the mobile-first, minimal, premium checkout UX direction.

Design rules:
- One centered buyer flow, max width on desktop.
- White/soft blue background, rounded cards, restrained shadows.
- Clear four-step mental model: intro, buyer info, instructions, status.
- Numbers and copy actions first.
- Short buyer-safe copy only.
- No SwimPay Intelligence internals exposed to the buyer.
- Respect mobile safe areas and reduced motion.

External inspiration:
- Used `ui-ux-pro-max` mobile UX rules.
- Used 21st/Magic component inspiration for stepper, compact checkout cards and copy actions.
