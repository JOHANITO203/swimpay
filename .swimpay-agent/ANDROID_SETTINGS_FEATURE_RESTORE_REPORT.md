# Android Settings Feature Restore Report

## Restored / preserved simple settings

- `Langue`
- `Apparence`
- `Sécurité`
- `Verrouillage de l'application`
- Google optional recovery/linking
- `Notifications`
- `Centre d'aide`
- `Contacter le support`
- `Confidentialité`

## Simplified

- `Sécurité & paramètres` became `Sécurité`.
- Technical sessions/devices block was removed from the default Security screen.
- `Integration developpeur` label became `Site connecté`.
- Settings business group changed from technical `BUSINESS` wording to user-facing activity wording.

## Not restored as fake UI

- Remote sessions/devices: no real repository exists.
- Advanced technical device/IP diagnostics: not merchant-facing and not restored.
