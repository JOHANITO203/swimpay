L'onboarding, photo et verre

Le parcours complet, jouable dans le téléphone. Tout fonctionne : le numéro, le code, le choix du profil, la liaison de chaque réseau par son SMS, la pièce (ajoute une vraie image), le régime fiscal et le code secret. Le parcours s'allonge si tu choisis Commerçant ou Entreprise.

    Pour voir les erreurs : le code 000000 est refusé, un numéro 05 sur la ligne Orange est refusé, et deux codes secrets différents ne passent pas.
    Réel, tiré de nos docs : les préfixes des lignes (07 Orange, 05 MTN, 01 Moov, Wave sur n'importe quel numéro), les cinq régimes fiscaux et leur code TVA, les tarifs des abonnements de la grille par défaut, le format du RIB UEMOA à 24 caractères.
    Exemples de maquette : les numéros, le RIB et le NCC pré-remplis. Tout code à 6 chiffres autre que 000000 est accepté.
